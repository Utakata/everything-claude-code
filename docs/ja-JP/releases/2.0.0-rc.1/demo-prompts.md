# Hermes x ECC デモプロンプト

## プロンプト1：ECC が ECC を作る

現在の ECC リポジトリと、`docs/releases/2.0.0-rc.1/` にある公開リリースパックを使用します。

以下の4つを順番に実行してください：

1. git status と現在のリポジトリの差分を検査し、ECC が ECC 自身を作るために使われていることを証明する、簡潔な ECC v2.0.0-rc.1 の PR またはリリースサマリーを提示する。
2. 強力な X スレッドを1つ仕上げる。
3. 強力な LinkedIn 投稿を1つ仕上げる。
4. 次に行うべき正確な3つの録画と、録画後に Hermes が自動生成できるものを教える。

決定的かつ実践的に保つこと。

## プロンプト2：録画を素材に変える

たった今、以下を録画したと仮定します：

- フェイスカメラのフック1つ
- Hermes が ECC を使って ECC v2.0.0-rc.1 を出荷する様子のスクリーンキャプチャ1つ
- Hermes x ECC ワークスペースのセットアップウォークスルー1つ

以下を提示してください：

1. X、LinkedIn、TikTok、YouTube Shorts 向けのショートフォーム編集プラン
2. クリーンな音声を録り直したい場合のボイスオーバースクリプト
3. 生の映像に使うべき、正確なリポジトリ相対のファイル名とフォルダ
4. ファイルを所定の場所に置いた後に Hermes が自動生成できる素材

オペレーショナルに保つこと。

## プロンプト3：公開ローンチのプッシュ

ECC v2.0.0-rc.1 のリリースパックを使って、以下を提示してください：

1. リリースツイート1つ
2. フォローアップツイート1つ
3. 投稿の下に貼り付けられる LinkedIn コメント1つ
4. このローンチをチャンネル横断で配信し続けるために、後で Hermes に送れる短い Telegram ハンドオフ1つ

ローンチスレッドの決まり文句ではなく、実際の作業を出荷するオペレーターのように聞こえるようにすること。
